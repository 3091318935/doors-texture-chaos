## 怎么下（不用梯子）

所有文件都能通过 gh-proxy 直连下载。把下面这段当前缀：

```
https://gh-proxy.com/https://raw.githubusercontent.com/Palayop7239/DoorsFiles/main/
```

后面拼上表里的「路径」（空格写成 `%20` 就行，浏览器地址栏会自动转）。例如：

```
https://gh-proxy.com/https://raw.githubusercontent.com/Palayop7239/DoorsFiles/main/floor2/figure%201st%20appear.rbxlx
```

浏览器直接粘贴回车就下，几十 MB 也是满速。

## 拿到文件之后

1. Studio → `File → Open from File` 打开 `.rbxlx` / `Insert from File` 插入 `.rbxmx`
   （`.zip` 先解压，里面是同类文件）
2. 在 Explorer 里找 `Workspace` 下的实体 Model —— 名字一般是 `Figure` / `Seek` / `Halt` / `Jeff` 之类
3. 整个 Model 复制，粘到你自己 place 的 `Workspace.Monsters` 下，重命名成标准实体名
4. 跑 [../standalone/DoorsTextureChaos.lua](../standalone/DoorsTextureChaos.lua) 或者装插件

> 原作者在 README 里提示的两个坑：
> · 打开后镜头被脚本锁死 → 把 Camera 类型设成 Custom，删掉 `StarterPlayerScripts` 里的 `PlayerModule`
> · `.rbxlx` 是反编译产物，不代表能直接跑，**只用来取模型和房间**

## 关于 Rush / Ambush

仓库里没有名字带 Rush/Ambush 的文件。它们要么在 `full run floor 1 (halloween event).rbxlx`（60 MB 整轮存档，最可能包含），要么在某个 `f1 rooms` / `mines rooms` 里。

如果翻遍了都没有，就走 `saveinstance` 自己抓（见 [models.md](models.md) 路线 0.1）—— 进游戏等它们真的冲到你面前再存。
